## ✨ 功能特性

### 🎬 视频助手
- **自动播放** — 进入视频页自动开始播放，无需手动点击
- **自动静音** — 播放时自动将网页静音，润物细无声
- **自动连播** — 当前视频播放完毕后自动切换到下一个课程
- **❌倍速设置** — 支持自定义播放速度（不支持）
- **疲劳检测屏蔽** — 自动关闭播放过程中弹出的"温馨提示""疲劳提醒"等对话框
- **双播放器兼容** — 同时支持保利威（Polyv）和 CC 播放器

### 📝 考试助手
- **试错算法** — 面向可多次提交的考试，自动遍历选项直到找到正确答案
- **正确答案记忆** — 记住已通过的正确答案，下次遇到相同题目自动填写
- **自动交卷** — 答题完成后自动提交试卷
- **结果页自动返回** — 考试结果页面自动返回课程列表继续学习
- **课堂问答自动试错（v2.2.1 新增）🏆 四创独有** — 华医网自有"课堂问答"组件（不走 Polyv 通道），自动依次点击选项→提交→弹窗消失即答对，答案记忆到 localStorage，下次直接命中

### 🧠 统一考核自动答题（独立脚本）🏆 四创独有
> 配套脚本：`hua-yi-exam-auto-answer.user.js`（另装，互不影响）

华医网**统一课程考核**（`sdnew.91huayi.com` 新考试系统）与旧版考试页结构完全不同，主脚本不覆盖。独立脚本内置 2026 公需课《人工智能赋能高质量发展》20 题题库（单选7+多选6+判断7），自动匹配题目→点选答案→切题，答完提示人工核对（**不自动交卷**）。题库可扩展：遇到新题在 `Q_BANK` 数组追加一条即可。

### 📋 课程列表自动扫描（v2.0.0 新增）
- 进入课程列表页自动按优先级扫描并进入学习：
  1. **未学习** — 最高优先级
  2. **播放至 x%**（x < 100） — 未完成课程
  3. **学习中** — 续播中断的课程
  4. **待考试** — 视频+考试模式下自动进入

- 屏蔽倍速检测定时器 `blockAbnormalPlugin`

> 📌 本仓库脚本**尚未发布到 GreasyFork**，请直接从本仓库下载安装。

### 手动安装

1. 安装 Tampermonkey 浏览器扩展（Chrome：[应用商店](https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo) / Edge：[加载项](https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaimahpihffkgbhfmcpkmf)）

4. 确认安装即可

### 统一考核自动答题助手（独立脚本）

## 🤝 完全适配 WorkBuddy

本脚本**不依赖油猴专有 API**，因此除了 Tampermonkey，也能直接被
[WorkBuddy](https://github.com/arthurfsy2) 等自动化框架注入运行，两种方式功能完全一致：

- **`@grant none`，零 `GM_*` 依赖** —— 全部逻辑为纯 DOM + `localStorage`，
  唯一用到的 `GM_info` 仅用于显示版本号，且已带非油猴环境的回退（v2.2.3 修复了
  该回退值不同步的问题）。
- **`@run-at document-start` 语义可复现** —— 用 Playwright 的
  `addInitScript` 注入即等价于油猴的 document-start 时机，反作弊拦截逻辑同样生效。
- **状态全部落在 `localStorage`** —— 模式切换、播放倍速、面板位置/透明度等，
  自动化框架复用浏览器 `storageState` 即可携带这些偏好，无需额外配置。

因此无论是「浏览器装油猴手动刷」还是「WorkBuddy 无人值守托管」，
用的都是同一份 `hua-yi-helper.user.js`，无需任何改动或分支版本。

### 附带的保活巡检 Skill

仓库内含一个 Claude Code / WorkBuddy skill：

## 🕳️ 官方禁用自动填充的蜜罐陷阱（v2.1.0 修复背景）

2026 年华医网登录页（`secure/login.aspx`）为阻止浏览器自动填充账号密码，使出了**三招组合拳**：

| # | 手段 | 效果 |
|---|------|------|
| ① | 密码框 `autocomplete="new-password"`、账号框 `autocomplete="off"` | 浏览器认为这是"注册新密码"场景，拒绝回填已保存的密码 |
| ② | 密码框 `type="text"`（伪装成普通文本框） | 破坏 Edge 识别"密码框"并提示保存的硬前提，浏览器根本不认为它是密码框 |
| ③ | `display:none` 隐藏蜜罐假框（标准 `username`/`password` 假框） | 即使浏览器尝试填充，也会被诱导把凭据填进看不见的假框，真实输入框依旧空白 |

**结果**：用户每次登录都必须手动输入账号密码，Edge 密码库形同虚设。

**本脚本的对策**（document-start 阶段、浏览器自动填充之前执行）：
1. 密码框还原为 `type="password"` + `autocomplete="current-password"`
2. 账号框还原为 `autocomplete="username"`
3. 蜜罐假框的 `autocomplete` 全部降级为 `off`，防止凭据被填入假框
4. 自动勾选「我已仔细阅读并同意」协议复选框

改造后登录页与普通网站无异：Edge 正常保存、自动回填账号密码，协议自动勾选，用户只需输入图形验证码即可登录。

## ⚠️ 已知限制

- **图形验证码** — 图形码无法可靠 OCR，需要用户手动输入一次（首次登录后 Edge 保存密码，后续只需输验证码）
- **考试助手** — 试错算法仅适用于允许多次提交的考试类型；若官方改为单次提交则该功能失效
- **多子域差异** — 华医网有多个子域（`cme28` 刷课、`hysslogin` SSO 登录、`xkjspc` 主站），各子域页面结构不同，脚本针对特定页面适配
- **学时上报** — 本地播放完成检测已解决切课问题，但"学完上报"仍依赖官方服务端异步更新，播完立即切课可能有几秒上报延迟（已用二次确认缓解）
